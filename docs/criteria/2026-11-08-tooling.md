## Criteria

1. **(T1, B, G, R)** Every workflow pins `actions/checkout` v7.0.1 to its commit.
   `persist-credentials` stays false.
2. **(T1, B)** The browser test lives at `know-your-loan/test/browser.test.js`. One command runs it,
   because it serves the app itself the way GitHub Pages lays it out. A `package.json` at the repo
   root pins the Playwright version it needs, with a lockfile.
3. **(B, C)** The browser test's sideways check measures every box against the screen's real width.
   It covers all three screens in all three languages, at 320 px and three wider phone widths up to
   393 px.
   It is shown failing on a copy of the app where Calculate scrolls sideways.
4. **(B, C)** The browser test passes on this branch. A workflow runs it, and the math tests, on
   every pull request.
5. **(T1, B)** A check fails a pull request that changes a file the app loads without changing
   `VERSION` in `sw.js`. These files do not count, since the app does not load them:
   - anything in `know-your-loan/docs/` or `know-your-loan/test/`
   - `know-your-loan/README.md` and `know-your-loan/NOTICE`
   - the two license files
6. **(B, C)** The VERSION check's logic is in a script with tests in the repo, each shown failing
   against a broken copy. The workflow runs those tests too.
7. **(B)** The pull request check's tests carry a `$(...)` on every line of their command text. A
   copy of the check that expands only one line fails them.
8. **(B)** The hook's reminder is valid JSON when a file name is not valid UTF-8. The hook's tests
   read the JSON strictly, and a test covers such a name. That test fails on the old hook.
9. **(C)** Nothing the app loads changes, so `VERSION` stays as it is and no screen changes.
10. **(C)** `CLAUDE.md` closes the five backlog items above in the same commit as the fix, and
    records each lesson. Its push checklist runs the browser test in place of the hand checks it now
    covers. The new checks stay optional until Tanya adds them to the ruleset, and a backlog item
    says so.
11. **(C)** Every new word follows Tanya's writing rules, comments in code included. Every date is
    Eastern time. Tanya is the author of every commit. Nothing new names anyone else or points
    outside this repo.
12. **(C)** The change lands by pull request. Its description says no screen changes, and it quotes
    the reviewers. It reports the workflow runs on the pull request itself, and it holds no link the
    tool added.
13. **(C)** Two independent reviewers check the change before it is pushed.
14. **(R)** The privacy check sees ordinary web traffic to another site, whether a page or the
    offline code sends it. Beacons sent as a page closes count too. It also sees links that open a
    connection early, even nested or changed later. It is shown failing on a copy that does each.
    The routes it cannot see are on the backlog, and nothing claims more.
15. **(R)** The print check reads the page laid out for print, not the PDF. It confirms that every
    line of the worksheet is there in the chosen language, read from the element that holds its
    words. That element must have height and count as visible to the browser. It counts the tick
    boxes and writing spaces the same way. It also looks for text and pictures outside the
    worksheet. Reviews found many ways past it, and the backlog lists them. It is shown failing on
    19 broken copies. One prints the calculator in place of the worksheet, and another hides every
    question.
16. **(R)** Nothing can hang: every job in both workflows has a time limit, and the test gives the
    offline code 15 seconds to install. The whole run stops after 5 minutes and fails. It is shown
    failing on three copies whose offline code is broken, one of them at the 5-minute limit.
17. **(R)** The VERSION check fails when either copy of `sw.js` lacks exactly one VERSION line. It
    counts a renamed file under both names.
